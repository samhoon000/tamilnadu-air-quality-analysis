# Tamil Nadu Air Quality Analysis

An exploratory data analysis (EDA) and air quality monitoring project focusing on air pollution levels across monitoring stations in Tamil Nadu, India.

## Project Structure

- `Data-Understanding.ipynb` - Initial data exploration, structure inspection, and preliminary statistical summaries.
- `Data-Cleaning.ipynb` - Data preprocessing pipeline handling missing values, standardizing column conventions, date conversions, and format normalization.
- `cpcb_dly.csv` - Raw daily air quality dataset from Central Pollution Control Board (CPCB) / TNPCB monitoring stations.
- `tamil_nadu_air_quality_cleaned.csv` - Cleaned and formatted dataset ready for analysis and visualization.

## Pollutants Monitored

- **SO2** (Sulphur Dioxide)
- **NO2** (Nitrogen Dioxide)
- **RSPM / PM10** (Respirable Suspended Particulate Matter)
- **PM 2.5** (Fine Particulate Matter)
